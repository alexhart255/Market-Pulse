📈 Interactive Brokers
Нет подключения
Шаг 1 — Введите данные IBKR
🔑 Interactive Brokers API
⚡ Как получить доступ IBKR:
Вариант A — Client Portal API (рекомендуется):
1. Скачайте Client Portal API Gateway с сайта IBKR Developers
2. Запустите: java -jar root/conf.yaml
3. Авторизуйтесь по адресу: https://localhost:5000
4. Account ID берётся из вашего аккаунта IBKR

Вариант B — TWS API:
1. Откройте Trader Workstation (TWS)
2. Edit → Global Configuration → API → Settings
3. Включите «Enable ActiveX and Socket Clients»
4. Порт по умолчанию: 7497 (paper) или 7496 (live)

🔒 Используйте только read-only разрешения.
